Built 2026-07-26: **Cohort/Funnel Analytics** tab in the Railway admin app (`pipeline/app.py`) to test the thesis that geographic-hub vendor density lifts revenue (signups × payment rate × ARPU). Xano-only v1, cached snapshot, in-memory cutting — never hammers Xano.

**Xano (new, group 10 "WeWeb Transparency Project"):**
- `analytics_users_export` (api id **205**) — slim, PII-free per-user projection (cohort fields + denormalized counters; NO name/email/password/tokens), secret-gated via `precondition`, paginated (follow `nextPage`; per_page=1000 → ~22 pages), response-cached 6h. `created_at` is access=private so exposed as eval alias `signup_at` (epoch ms).
- `analytics_hub_stats` (api id **206**) — tiny hub_key→vendor_count/venue_count for density tiers.
- Secret (embedded in both endpoints AND `analytics.py` default): `[token]`. Move to `$env` / Railway env `ANALYTICS_EXPORT_SECRET` to rotate. Backups: `.claude/xano_backups/analytics_users_export_v1_2026-07-26.xs`, hub_stats created inline.

**Railway (new files):** `pipeline/analytics.py` (self-contained: retry-hardened pull, background-refreshed pandas snapshot w/ 6h TTL + disk cache at tempdir/tulle_cohort_snapshot.json, 5 routes `/api/cohorts/{meta,summary,funnel,table,retention}` + `/refresh`), registered in app.py via `register_analytics(app)`. Added `pandas==2.2.2` to requirements. New "Analytics" tab in `templates/index.html` (Chart.js CDN; funnel bar, retention line, cohort table default grouped by density_tier, interactive filter cutter, stat tiles). Cuts: planning_phase, age, referral, intent, area, hub_key, density_tier, budget/guest buckets, signup_month, hub_mapped + numeric thresholds min_vendor_views/min_pdf_views/min_payments + signup date range. Excludes role in {admin,test,staff,superadmin,dev}.

**Verified live (21,479 analysis users):** thesis holds — pay rate by density tier High 3.94% / Medium 3.2% / Unmapped 2.52% / Low 0.61%; ARPU $2.16/$1.56/$1.39/$0.43. Filtering High-density + viewed-a-PDF → pay 8.33%, ARPU $4.62. Full app boots locally, page renders, background snapshot ~27-34s, disk cache persists.

**Data realities found (tell user / action items):**
- `total_amount_paid` is **DOLLARS** (verified: $38,629/717 payers=$53.88 ≈ $30/$75 plans; ~$183/day). Units resolved.
- **`total_pdf_submissions` is 0 for ALL users** — counter unpopulated upstream; the "Submitted a PDF" funnel step reads 0 until someone increments it in the Xano PDF-submission flow.
- **`last_active_at` fill rate ~3.45%** (backfills forward from ~2026-07). Retention = last-active survival proxy computed only over users WITH activity data; reliable only for recent cohorts (2026-07 has ~586 with activity vs 10-33 for older months).

**v2 (2026-07-26, same session):** ARPU redefined = revenue/PAYING user (so revenue = signups × pay_rate × ARPU; old per-signup kept as `rev_per_signup`). Dropped total_pdf_submissions everywhere (all-zero). Retention note now "last_active_at live since 2026-07-21" (`_BACKFILL_START`). Added 4 insight features (all in analytics.py + index.html, NO Xano change): **auto-insights** `/api/cohorts/insights` (Wilson-ranked movers vs baseline, min n=200, z-test significance), **revenue Pareto** (table gained revenue+rev_share, Pareto chart), **density scatter** `/api/cohorts/density` (per-hub vendor_count vs pay_rate/ARPU + Pearson r; needs `_snap["hub_meta"]` from refactored `_pull_hubs`), **engagement curve** `/api/cohorts/engagement` (pay_rate/ARPU by view buckets 0/1/2-3/4-10/11+). ARPU/payer ~flat across tiers (~$49-70) so density lifts pay RATE not per-payer spend.
