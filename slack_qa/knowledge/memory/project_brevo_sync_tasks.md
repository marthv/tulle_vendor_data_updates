- **Brevo API constraint (researched):** NO API for Automations-product stats. Per-sequence open/CTR only reachable by tagging each automation's email steps in Brevo UI, then `aggregatedReport?tag=<seq>`. v1 is account-wide; per-sequence is the documented FOLLOW-UP (convention e.g. `seq_viewed0`/`seq_viewed12`/`seq_access_expiry`/`seq_viewed_all`). Other Brevo stat endpoints: `/v3/emailCampaigns` = classic/trigger campaigns only (not automations); marketing webhooks lack template/workflow id (transactional webhooks have template_id+message_id+tag).
- Brevo date-param gotcha: `createdSince` needs full ISO with **Z** suffix (the `+00:00` offset breaks in URL; date-only rejected); `aggregatedReport` startDate/endDate need **date-only YYYY-MM-DD** (max 90-day window).
